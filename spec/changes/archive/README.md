# Arquivo de mudanças

Mudanças concluídas e verificadas são movidas para esta pasta.

## Convenção

```text
spec/changes/archive/YYYY-MM-DD-slug-curto/
```

Cada pasta arquivada MUST manter `proposal.md`, `design.md`, `tasks.md` e `spec-delta.md`, com o status atualizado para `archived`.

## Antes de arquivar

- [ ] Código e testes concluídos
- [ ] `spec-delta.md` reflete o estado final
- [ ] Spec do módulo e cenário BDD atualizados
- [ ] README/help/CHANGELOG atualizados quando aplicável
- [ ] Status alterado para `archived` na proposta
